This is a design walkthrough for engine telemetry in Data API builder, or Dab. Nothing shown here is a new working telemetry feature, and we have not run a cloud proof of concept. The goal is to make three decisions easier to review: which properties are worth collecting, what their names should mean, and where the telemetry should be managed. We will compare two Application Insights operating models, including an optional move to Data X later. The detailed design document remains the reference for the full property catalog and supporting sources.
