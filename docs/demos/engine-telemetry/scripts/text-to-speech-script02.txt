The direction is to reuse Application Insights, not build a telemetry platform. Application Insights can carry events and properties that we define. Its supported client handles the service protocol and delivery mechanisms, and Azure supplies managed storage and analysis. That avoids inventing a receiver, transport, or dedicated analytics cluster just to count feature adoption. But reuse does not mean zero engineering. Dab still needs to compute the approved facts, control consent, filter unwanted data, and test behavior. We also need to confirm the supported dot net client and authentication path for software running outside Microsoft's infrastructure.
