The candidate properties fall into three groups. Context includes product version, operating system family, execution mode, and database types. These help prioritize support, but increasingly precise combinations can identify a deployment. Configuration states tell us which features are enabled. The document accounts for the existing twenty runtime and fourteen entity fingerprint positions, without sending entity names. Observed usage is different: protocol categories, logical operation counts, cache activity, and coarse outcomes need explicit instrumentation and an aggregation window. Their benefit is knowing what people actually exercise. Their costs include extra collection work, volume, and privacy review. This is a menu, not one giant payload.
