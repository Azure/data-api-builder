Names should preserve meaning, even if the destination changes. Our working convention uses flat Dab-prefixed names. Configuration fields describe settings, while usage fields describe activity in a defined window. Units and bucket labels should be explicit. Missing must not silently mean disabled, and unsupported must not mean false. A logical operation count is not necessarily an H T T P request count. An engine process identifier is not Application Insights' user session identifier. We also distinguish the time an event occurred from the time a server received it. These are small naming decisions with a large effect on query correctness.
