Both operating models use Application Insights-based collection. In the first, the Dab team manages an Application Insights resource in Azure Monitor. Its logs live in a linked Log Analytics workspace, and authorized readers use K Q L, dashboards, or query interfaces. In the second, the Data X guide starts with testing in our own Application Insights resource, then describes a switch to a platform-provided destination. Data X adds processing, classification, shared Kusto storage, and requested analytics. AdVent is one analysis application, not the ingestion endpoint. This does not prove that every exporter is interchangeable or that the handoff is only a key change.
