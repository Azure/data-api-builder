Keeping the telemetry in Azure Monitor is the more self-contained option. We obtain approved resources, configure the supported client, and build the product queries we need. Azure operates ingestion and storage; our team owns resource policies, budgets, access, and data quality. The same custom events appear under different table and field names in Application Insights and Log Analytics. We must use the right query schema. This approach can be enough for version and feature trends. Its main tradeoff is retaining more data-management responsibility, plus validating privacy, sampling, and external publishing rather than assuming the defaults are safe.
